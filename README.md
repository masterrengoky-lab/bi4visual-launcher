# KissLauncherVis

Лаунчер Minecraft: Java Edition в тёмно-фиолетовом стиле.

## Как поставить

Скачайте `KissLauncherVis.bat` из последнего релиза `kiss-v*` и запустите двойным кликом. Батник сам скачает установщик, тихо поставит лаунчер и откроет его. Потом этот же батник просто запускает лаунчер.

## Что умеет

- Главная: большая кнопка «Играть», выбор сборки, аккаунта и языка.
- Косметика: бесплатные плащи, крылья и головные уборы на 3D-модели скина.
- Скины: скины игроков по нику (Mojang), загрузка своих PNG, «Мои скины».
- Моды и ресурспаки из Modrinth и CurseForge (для CurseForge нужен бесплатный API-ключ в настройках).
- Сборки: любая версия Minecraft, Fabric, Forge, NeoForge, Quilt; модпаки Modrinth в один клик; копия сборки.
- Друзья: список по нику с головой и скином для лицензионных ников.
- Аккаунты: без пароля по нику или Microsoft, несколько аккаунтов.
- Сам скачивает нужную Java.
- Языки: русский, английский, украинский.

## Сборка из исходников

Нужны [Rust](https://rustup.rs), [Bun](https://bun.sh) и [зависимости Tauri](https://tauri.app/start/prerequisites/).

```sh
bun install
bun run tauri dev
bun run tauri build
cargo test -p kiss-core
```
