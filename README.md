# Джарвис — голосовой помощник для Windows

Слушает микрофон, по слову «Джарвис» принимает команду, понимает её с помощью ИИ и сам выполняет
действия на компьютере. Отвечает голосом. Команды можно и печатать прямо в окне.

## Готовая программа (проще всего)

Скачай `Jarvis.exe`, положи его в отдельную папку (например `Рабочий стол\Jarvis`, рядом он сохранит
настройки) и запусти. При первом запуске он спросит, какой «мозг» включить. Если Windows покажет
«Система Windows защитила ваш компьютер», нажми «Подробнее» и «Выполнить в любом случае»: программа
просто не подписана сертификатом.

## Установка из исходников

1. Распакуй архив в любую папку, например `C:\Jarvis`.
2. Запусти `install.bat`. Он сам поставит Python (если нет), библиотеки, модель распознавания русской
   речи, и спросит, какой «мозг» настроить:
   - **локальный (Ollama)**: бесплатно, без интернета, но нужна видеокарта от 8 ГБ. Скачается модель
     `qwen2.5:7b`, около 4,7 ГБ;
   - **облачный (Claude)**: самый умный, нужен ключ API с https://console.anthropic.com/settings/keys
     (платно, по факту использования);
   - **оба**.
3. Запусти `run.bat` и скажи: «Джарвис, открой браузер».

`run_text.bat` запускает помощника без микрофона, только текстом (удобно для проверки).

## Что можно говорить

- «Джарвис, открой Телеграм / Steam / Майнкрафт / блокнот»
- «Найди на ютубе лоу-фай музыку», «Открой вк»
- «Сделай громкость 30», «Выключи звук», «Следующий трек», «Пауза»
- «Сверни все окна», «Переключись на Дискорд», «Закрой хром»
- «Какая погода в Москве?», «Сколько времени?»
- «Напомни через 10 минут выключить чайник»
- «Найди на компьютере файл с отчётом», «Создай на рабочем столе папку Проекты»
- «Сколько свободного места на диске?», «Что жрёт память?»
- «Напечатай: привет, я скоро буду» (печатает в активное окно)
- «Посмотри на экран и скажи, что тут написано» (только облачный режим)
- «Запомни, что мой ник bi4visual»
- «Заблокируй компьютер», «Выключи компьютер через час»
- Всё остальное помощник делает через PowerShell: «Включи тёмную тему», «Покажи мой IP»,
  «Установи VLC» и т.д.

После ответа 6 секунд можно говорить без слова «Джарвис», чтобы продолжить разговор.

Служебные фразы: «переключись на облачный», «переключись на локальный», «новый разговор»,
«помолчи» / «говори», «отбой» (закрыть помощника).

## Безопасность

Всё опасное спрашивает подтверждение голосом («да» / «нет»): удаление (только в корзину), перезапись
файлов, перемещение, принудительное закрытие программ, выключение и перезагрузка, PowerShell-команды,
которые что-то удаляют или меняют в системе. Отключается в `config.json` (`confirm_dangerous`), но лучше
не надо.

## Настройки (`config.json`)

| Поле | Что значит |
| --- | --- |
| `name`, `wake_words`, `greeting` | имя помощника, слова-активаторы, приветствие |
| `brain` | `ollama` или `claude`, какой мозг включать при запуске |
| `claude.api_key` | ключ API (или переменная окружения `ANTHROPIC_API_KEY`) |
| `claude.model` | модель, по умолчанию `claude-opus-5-5`; дешевле: `claude-sonnet-5-5`, `claude-haiku-5-5` |
| `claude.effort` | `low` быстрее и дешевле, `medium`/`high` умнее на сложных задачах |
| `claude.web_search` | разрешить поиск в интернете для ответов на вопросы |
| `ollama.model` | локальная модель, например `qwen2.5:7b` или `qwen2.5:14b` (умнее, нужна видеокарта мощнее) |
| `tts.engine` | `edge` (красивый нейроголос, нужен интернет) или `sapi` (голос Windows, офлайн) |
| `tts.edge_voice` | `ru-RU-DmitryNeural` (мужской) или `ru-RU-SvetlanaNeural` (женский) |
| `stt.model_path` | модель распознавания; для лучшего качества можно скачать большую `vosk-model-ru-0.42` (1,8 ГБ) с https://alphacephei.com/vosk/models и указать её папку |
| `stt.mic_device` | номер микрофона, если по умолчанию выбирается не тот |
| `follow_up_sec` | сколько секунд после ответа слушать без слова-активатора |

Если «Джарвис» плохо распознаётся, добавь в `wake_words` то, что пишется в окне в строке «(слышу: …)»,
или смени имя на обычное слово, например «компьютер».

## Облачный режим: сколько стоит

Одна простая команда обычно стоит около 1–3 центов на `claude-opus-5-5` (повторяющаяся часть запроса
кэшируется и стоит дешевле). Если хочется дешевле, поставь в `claude.model` значение `claude-haiku-5-5`.
Если облачная модель откажется отвечать, запрос автоматически повторяется на запасной модели.

## Файлы

- `assistant.py` — главный цикл: микрофон, слово-активатор, подтверждения
- `jarvis/tools.py` — все действия на компьютере (добавить своё: функция с декоратором `@tool`)
- `jarvis/brains.py` — облачный и локальный ИИ
- `jarvis/speech.py` — распознавание речи (Vosk), `jarvis/voice.py` — голос
- `notes.json` — то, что помощник запомнил о тебе
